# 烧录重建与交付依赖复查

从最终RAR重新解压独立副本，核对赛题一的基础要求、高阶挑战及相应交付资料。源码、IP、外设和时序约束、CPU ROM、五套模型来源、网络结构与统计、标准网络对比及原始实测均在包内。

|复查入口|结果|
|---|---|
|完整清单与原始证据核验|通过，归档中所有文件与哈希清单一致|
|五模型恢复|三套从参数代码生成、两套从训练检查点导出，均与最终权重逐字节相同|
|C固件源码编译|通过，28586字节，未安装或替换归档ROM|
|归档原生实现生成配置|通过，解码配置1102538字节|
|完整Flash重建|通过，4214816字节；固定256字节原生工具文件头之后全部字节与交付镜像一致|
|五槽模型区|与交付NNW1及完整Flash模型区逐字节一致|

原生工具会更新固定文件头中的生成元数据，因此比较时分别检查文件头与实际配置/模型载荷，不把元数据变化当作逻辑变化。最终烧录入口仍为`04_烧录文件/OSD_SIMPLE_SELECTED5_FULL_FLASH.hex`。

构建入口补充了原生Efinity阶段的英文临时目录处理，覆盖中文工程名称下的位流生成；生成结果回存工程，最终部署镜像保持原内容。操作仅创建本机文件，没有连接或烧录开发板。

`RECONSTRUCTION_CHECK.json`保留长度、模型一致性和镜像哈希；`pgm.log`、`native_pgm.out`为成功生成配置的原始记录；`WEIGHT_REBUILD.json`记录五模型重建结果。完整源码逐项索引见项目`05_技术资料/赛题提交总览.md`。
